🚀 How to Make This Website Live on Vercel (100% Free)

Your project is already configured with vercel.json and serverless API handlers. You can deploy it in less than 2 minutes!

Method 1: One-Click Windows Script (Fastest)

Double-click the script in your project folder:

C:\IELTS Preparation Website\deploy-vercel.bat

It will run npx vercel. You will be prompted in your browser to log in (or create a free account), then press Enter to deploy!

Method 2: Via PowerShell Command Line

Open PowerShell in your project folder and run:

cd "C:\IELTS Preparation Website"
npx vercel --prod

When asked "Set up and deploy?", type Y and accept the defaults. Vercel will instantly return your live public URL!

Method 3: Via GitHub & Opera GX

  1. Create a new repository on GitHub (e.g. ielts-speaking-pro).
  2. Push this folder to GitHub.
  3. Go to vercel.com in Opera GX, log in, click "Add New Project", and select your repository.
  4. Click Deploy. Vercel builds and publishes it automatically!
