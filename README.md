# 🎯 IELTS Speaking Band 8+ Mastery Platform

An AI-powered IELTS Speaking simulation and evaluation web platform designed to help test-takers score Band 8.0+.

## ✨ Features
- **3-Phase Simulation**: Part 1 Introduction, Part 2 Cue Card (with 1-min preparation timer & scratchpad), and Part 3 Analytical Discussion.
- **7-Criteria Evaluation Engine**: Evaluates Fluency, Coherence, Lexical Resource, Idiomatic Collocations, Grammatical Complexity, Grammatical Accuracy, and Delivery Cadence.
- **Band 8.5+ Native Rephraser**: Rewrites candidate answers into authentic C2 native English while preserving personal experiences.
- **Vocabulary Upgrade Matrix**: Identifies elementary adjectives and expressions and suggests high-band replacements.
- **AI Question Generator**: Generates custom IELTS tests dynamically for any topic (offline procedural engine + Gemini LLM).
- **Real Exam Recollections**: Up-to-date question bank with real IELTS exam questions from 2024–2026 sittings.
- **Vercel Serverless Ready**: 100% free hosting with persistent local storage.

## 🚀 Deployment to Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other** (Root directory: `./`).
3. Click **Deploy**!
